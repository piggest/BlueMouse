使い方ガイド

BlueMouse は、iPhone を Bluetooth LE 経由で Mac や Windows のタッチパッド・キーボードとして使えるアプリです。このページでは、各画面の操作方法と、つまずきやすいポイントをまとめます。

構成

BlueMouse は 2 つのアプリで動作します。

  • iPhone アプリ　BLE ペリフェラルとして広告し、画面のタッチをイベントとして送ります。
  • レシーバー（Mac / Windows）　BLE セントラルとして iPhone を見つけ、受け取ったイベントを OS のマウス・キーボード入力に変換します。

動作環境

BlueMouse の利用に必要な OS バージョンと、Bluetooth まわりの要件です。

iPhoneiOS 16 以降。Bluetooth が有効であること。
Mac レシーバーmacOS 13 Ventura 以降。Apple Silicon / Intel どちらにも対応。
Windows レシーバーWindows 10 1809 以降 (BLE 対応の Bluetooth アダプタが必要)。
通信PC 内蔵の Bluetooth (BLE) のみを使用。Wi-Fi、USB ケーブル、PC に挿す USB レシーバーは不要。

注意　Windows 環境では、古い Bluetooth アダプタが BLE に対応していないことがあります。デバイスマネージャで「Bluetooth LE」関連のスタックが見えるか確認してください。

セットアップ

iPhone とレシーバー双方の初期設定の流れです。

1. iPhone アプリのインストール

  • BlueMouse の iPhone アプリをインストールし、起動してください。
  • 初回起動時、Bluetooth の利用許可ダイアログが表示されます。許可してください。

2. レシーバーのインストール

  • 使用する OS に対応するレシーバーをダウンロードしてください。
  • Mac の場合: BlueMouseReceiver.app を /Applications に配置します。
  • Windows の場合: 配布されたインストーラまたは .exe をセットアップしてください。

3. 初回接続

  • レシーバーを起動すると、メニューバー（または通知領域）に BlueMouse のアイコンが表示されます。
  • iPhone アプリ側を開くと、レシーバーが自動でスキャンを始め、新しい端末として検出されます。
  • レシーバーのメニューから対象 iPhone を選び、「許可」してください。一度許可した端末は次回以降自動で再接続します。

タッチパッドモード

iPhone の画面をマルチタッチのトラックパッドとして使います。

基本ジェスチャー

操作動作
1 本指でなぞるカーソルを移動します。
1 本指で軽くタップ左クリック。
2 本指で軽くタップ右クリック。
2 本指で上下になぞる縦スクロール。
2 本指で左右になぞる横スクロール。
長押し → そのまま移動ドラッグ操作。

カーソル加速

指の動きが速いほどカーソル移動量が大きくなる加速カーブを採用しています。細かなピクセル単位の作業から、画面の端まで大きく動かす操作まで、同じ感覚で行えます。

中央ボタン領域

画面下部には中央ボタン用の領域があります。タップ・長押し・ダブルタップに、用途に応じた追加クリックを割り当てられます。

スクロール専用領域

画面右端には縦スクロール専用、下端には横スクロール専用の細い帯があります。スワイプ操作と区別せずに、確実にスクロールを行いたい場面で活用してください。

キーボードモード

iPhone のソフトウェアキーボードで PC に文字入力できます。

切り替え方

  • iPhone アプリの画面下部にあるモード切替から「キーボード」を選びます。
  • 入力したテキストはリアルタイムにレシーバー側へ送信され、PC のフォーカス位置に挿入されます。

日本語入力

iPhone の標準 IME がそのまま使えるため、PC 側の IME 環境に左右されません。日本語キーボードを持っていない海外メーカーの PC でも、iPhone があれば日本語入力が可能になります。

特殊キーの送信

Return キーや Backspace は、iPhone のキーボードのものをそのまま PC 側に送ります。BackspaceDetectingTextField により、変換中の文字消去も正確に伝達されます。

キーボードモードでは、PC 側に HID Keyboard として動作するため、ログインプロンプトや UAC ダイアログでも文字入力に利用できます。

デバイス信頼

許可した iPhone だけが接続できる仕組みです。

許可と拒否

  • 初めて検出された iPhone は 未知の端末 として表示され、操作はブロックされます。
  • レシーバーのメニューから「許可」を選ぶと、その iPhone はデバイス ID として記録され、以降は自動で接続が確立します。
  • 「拒否」を選んだ iPhone は記録され、明示的に解除するまで再接続を試みません。

デバイス ID 方式

BlueMouse は MAC アドレスではなくアプリ側で発行する一意のデバイス ID で iPhone を識別します。OS による BLE アドレスのプライバシー対策で接続が不安定になることを避け、再接続の信頼性を高めています。

許可済みリストの確認

レシーバーのメニューから、許可済み・拒否済みの iPhone 一覧をいつでも確認できます。誤って許可してしまった端末は、メニューから外すと次回以降は再び未知扱いに戻ります。

Mac レシーバー

macOS のメニューバーに常駐するレシーバーアプリです。

メニュー項目

  • 接続状態の表示（接続中の iPhone 名 / スキャン中 / 未接続）。
  • 許可済みデバイスの一覧と切り替え。
  • 未知の端末への許可・拒否操作。
  • 環境設定、終了。

権限

初回起動時に アクセシビリティ 権限の許可を求められます。これは PC 側でカーソル移動とクリック・キーストロークを発行するために必要です。

カーソル精密移動

Mac レシーバーは SetCursorPos 相当の API を用いてカーソルを直接動かし、整数座標への丸めによるブレを最小化しています。

Windows レシーバー

Windows のシステムトレイに常駐するレシーバーアプリです。

機能

  • トレイアイコンが接続状態に応じて変化します。
  • 接続通知・切断通知をトーストで表示します。
  • ログイン時に自動起動するオプションを用意しています。
  • 動作ログをファイルに出力し、トラブルシューティングに利用できます。
  • バージョン情報をメニューから確認できます。

カーソル移動

SetCursorPos を使ってカーソルを動かし、サブピクセル単位の累積誤差を排除しています。

キー送信

HID Usage Code を Windows のスキャンコードへ変換するマップにより、日本語キーボード固有のキーや、ファンクションキーも正しく送信されます。

使いこなしのヒント

日常的に便利な使い方の例です。

  • プレゼン用リモコン　PC をプロジェクタへ繋いだまま、iPhone から手元操作。
  • キーボード非搭載の Mac mini / NUC　常設のマウス・キーボードを置く場所がない PC の操作に。
  • 離れた場所からの操作　BLE の届く範囲（数メートル）であれば、ソファや机から離れて使えます。
  • 日本語入力環境のない PC　海外向け Windows でも iPhone の IME で日本語入力可能。

トラブルシューティング

よくある問題と対処法です。

iPhone が検出されない

  • iPhone 側の Bluetooth が ON になっているか確認してください。
  • iPhone アプリがフォアグラウンドで起動しているか確認してください（バックグラウンドではアドバタイズを停止します）。
  • レシーバーの「再スキャン」を実行してください。

接続するが操作できない

  • Mac の場合、システム設定 > プライバシーとセキュリティ > アクセシビリティ で BlueMouseReceiver が許可されているか確認してください。
  • Windows の場合、トレイアイコンが「接続中」状態になっているか確認してください。

切断・再接続を繰り返す

  • BLE の電波干渉（多数の Bluetooth 機器、強い Wi-Fi 5GHz など）を疑ってください。
  • レシーバーを一度終了し、再起動することで内部状態がリセットされます。

カーソルが少しずれる・震える

最新版では整数座標への直接配置によりこの問題を解消しています。旧バージョンを使用している場合は、最新リリースに更新してください。
