BlueMouse

iPhone を、Mac と Windows のタッチパッドに。

Bluetooth LE で iPhone と PC を直接つなぎ、画面をタッチパッド・キーボードとして使えるユーティリティ。専用ドングルやサーバーは不要。

最新版をダウンロード 使い方ガイド

iOS 16+ / macOS 13 Ventura 以降 / Windows 10 (1809) 以降

できること

  • タッチパッド

    iPhone の画面をマルチタッチのトラックパッドとして使えます。1 本指で移動、2 本指でスクロール、軽いタップでクリック。

  • キーボード

    iPhone の標準キーボードでそのまま入力。日本語 IME や Bluetooth キーボード非搭載のデスクでも安心です。

  • BLE 直結

    専用ドングルや Wi-Fi、ペアリングサーバーは不要。iPhone と PC を Bluetooth LE で直接つなぎ、低遅延で動作します。

  • Mac / Windows 対応

    macOS 用と Windows 用のレシーバーを用意。どちらの環境でも同じ iPhone から操作できます。

  • デバイス信頼方式

    初回接続時に許可した iPhone を覚えておき、以降は自動で接続。知らない端末からの接続は明示的な許可が必要です。

  • カーソル加速

    指の速度に応じてポインタの移動量を調整。細かい作業も、大きな移動もストレスなく行えます。

  • スクロール領域

    画面の端を縦・横スクロール専用領域に設定可能。長文ドキュメントや表の操作が快適になります。

  • 切替簡単

    レシーバー側のメニューから接続先 iPhone をワンクリックで切り替え。家族や複数台での共有もスムーズ。

対応プラットフォーム

送信側

iPhone アプリ

iPhone 上で起動するメインアプリ。タッチを BLE で送信します。iPad でも動作します。

iOS 16 以降。App Store からは未配布、TestFlight またはセルフサイドロード。

受信側

Mac レシーバー

メニューバーに常駐し、iPhone からの入力を Mac の HID イベントに変換します。

macOS 13 Ventura 以降。Apple Silicon / Intel どちらにも対応。

受信側

Windows レシーバー

システムトレイに常駐し、Windows 上で iPhone をマウス・キーボードとして扱います。

Windows 10 1809 以降。BLE 対応の Bluetooth アダプタが必要。

使い始める

  1. iPhone に BlueMouse アプリをインストールします。
  2. Mac または Windows に対応する レシーバー をインストールして起動します。
  3. iPhone 側でアプリを開き、レシーバーから「許可」を選んで初回接続を確立します。
  4. 以降は自動で再接続。タッチパッドモードとキーボードモードを切り替えて使えます。

受信側 PC で Bluetooth が有効になっており、BLE が利用できる必要があります。
